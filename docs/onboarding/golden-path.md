# Golden Path de onboarding

**Meta:** que un ingeniero nuevo despliegue un cambio en producción en su segunda semana (hoy tarda 6).

## Semana 1: entorno y contexto

- [ ] Acceso a GitHub, Jira, Slack y PagerDuty.
- [ ] Clonar este repositorio y abrirlo en Obsidian.
- [ ] Leer el [[mapa-de-servicios]] y los ADRs en `docs/adr/`.
- [ ] Levantar el entorno local siguiendo el README de `services/notificaciones/`.

## Semana 2: primer cambio real

- [ ] Resolver una tarea etiquetada como `good-first-issue`.
- [ ] Hacer un PR que incluya, si aplica, la actualización del runbook.
- [ ] Hacer un ejercicio de runbook: seguir `services/notificaciones/runbook.md` en staging.
- [ ] Leer dos post-mortems de `docs/incidents/`.

## Quién responde preguntas

Cada servicio indica su responsable en su README. Las preguntas que se repiten deben convertirse en una entrada de esta guía.
